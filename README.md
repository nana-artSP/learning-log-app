# 学習ログ管理アプリ

## 概要
日々の学習時間を記録・管理するために作成した Web アプリです。  
ログイン後に学習ログの追加・一覧表示・編集・削除ができます。  
また、開始時刻と終了時刻を利用したタイムカード風の学習記録にも対応しています。

## 起動方法

### 1. FastAPI を起動

### 2. Flask を起動
python app.py

### 3. ブラウザでアクセス
http://127.0.0.1:5000/login
